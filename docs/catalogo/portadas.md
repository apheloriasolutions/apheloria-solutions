# Portadas de las secciones de Productos

Las ocho grandes familias no tienen una foto propia, así que su portada son imágenes
de bancos libres. Todas con licencia **CC0** (dominio público): se pueden usar con fines
comerciales y no exigen atribución. Se dejan apuntadas aquí por si hiciera falta.

Se cambian en `data/textos.json`, con la clave `portada` de cada sección, y se publican
volviendo a ejecutar `scripts/catalogo/construir_web.py`.

| Sección | Título original | Banco | Licencia | Publicada |
|---|---|---|---|---|
